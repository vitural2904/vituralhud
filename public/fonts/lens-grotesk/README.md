# Lens Grotesk files

Place licensed files here:

- `LensGrotesk-Light.woff2`
- `LensGrotesk-Bold.woff2`

15 WOFF2 files were converted from the user's supplied `D:\Downloads\Lens Grotesk` folder. Available: Thin, ExtraLight, Light, Book, Medium, SemiBold, Bold, their italics, and Regular. ExtraBold is not in this bundle. Each face loads independently. Book owns the 400 slot; the separate Regular face is registered as `Lens Grotesk Regular`.

Supported weight names: `Thin`, `ExtraLight`, `Light`, `Book`, `Medium`, `SemiBold`, `Bold`, `ExtraBold`. Use `LensGrotesk-{Weight}.woff2` for upright faces and `LensGrotesk-{Weight}Italic.woff2` for italics.

Typography roles: Light for body copy; Book for fields and player names; Medium for controls; SemiBold for labels; Bold for headings and key values. Thin is reserved for the large post-match duration. Light Italic is reserved for the workspace description. Thin and Italic activate only when the real files exist. No synthetic italics or weights.

Be Vietnam Pro covers missing glyphs and is used when neither Lens file exists. Font files stay local and are ignored by Git. Do not commit trial or unlicensed font files.
